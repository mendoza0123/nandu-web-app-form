## Fit-Spec Reference (to lock per garment type)

For shirts (core Vhagar product) — measurements to track per size (S/M/L/XL/XXL):
- Collar band (cm)
- Chest circumference (cm)
- Shoulder width (cm)
- Sleeve length (cm)
- Body length (cm)
- Sleeve opening circumference (cm)

**Tolerance bands to enforce:**
- Chest: ±0.5 cm
- Collar: ±0.3 cm
- Shoulder: ±0.5 cm

All tolerance bands stored at Cotton factory + Naushi's design files. Pre-drop QC checks every unit against the block.

## Shrinkage Disclosure

- Cotton shirts: 3–5% shrinkage expected. State pre-wash vs post-wash size on product pages.
- Poly-cotton blends: 1–3%
- Test-wash before every new fabric introduction.

## Drop Model

- **Core catalog**: base shirts range always available (799–1799 essentials)
- **Drops**: periodic themed releases creating scarcity + freshness
- **At 1–3 drops**: every drop is a learning exercise, not a brand-builder

### Post-Drop Review Protocol (Within 48 Hours of Every Drop)
1. What sold? What returned? What fit feedback came in?
2. What did the agency deliver vs what was expected?
3. What's the return-by-size breakdown?
4. What organic engagement came from this drop?
5. What's the repeat purchase signal from prior drop buyers?

## Trend Radar — 4-Signal System

| Signal | What It Looks Like for Vhagar |
|---|---|
| **1. Customer Pull** | Reviews + DMs asking for specific styles, colors, fits |
| **2. Runway / Influence** | Instagram aesthetics, celebrity wardrobes, menswear reports |
| **3. Supply-Side Proof** | Linkd already printing that print style; Silk already stocking that base fabric |
| **4. Margin Test** | A small first drop of that style sold through at target margin |

**Decision rule**: 3 of 4 signals = pilot drop. 4 of 4 = full-confidence drop. Never commit a full drop on 1–2 signals.

**Categories to watch:**
- Silhouette: oversized vs fitted (current Indian menswear cycle)
- Print: abstract / geometric / florals / solids with texture
- Fabric story: natural / sustainable angle (linen, organic cotton)
- Smart casual / elevated basics (sweet spot for 799–1799 aspiring premium)

### The Feedback Flywheel

Vhagar is the **end-consumer feedback loop for the entire vertical stack**:
- Vhagar returns → Cotton DHU improvement (poor garmenting)
- Vhagar fit feedback → Cotton sizing + block system improvement
- Vhagar print quality complaints → Linkd calibration improvement
- Vhagar "this fabric doesn't feel right" → Silk procurement signal

**Protecting Vhagar protects Cotton and Linkd simultaneously.**
