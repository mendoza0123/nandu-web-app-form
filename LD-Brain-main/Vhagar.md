## SECTION 5 — THE BOMB: FIT INCONSISTENCY

### Current Status (Phase 0.5)
- **NOT LOCKED**. Fit varies across sizes AND across drops. Same "M" from two drops can fit differently.
- **Return rate**: Under 10% (better than feared for D2C fashion at 799–1799 in India)

### Reframe: Not an Emergency — An Unlock
At <10% returns, fit inconsistency is **NOT an active emergency**. Customers tolerate some variance at 799–1799.

**BUT**:
- At 2,500+ (the aspiration): customers expect locked fit. Inconsistency kills repeat purchase and justifies returns.
- **Fit-lock sprint is what enables the pricing journey from 799–1799 → 2,500+ → Rare Rabbit tier.**
- Without locked fit, the vertical story ("our own factory") is a liability not an asset — because the factory's inconsistency becomes the brand's inconsistency.

### The Fit-Lock Sprint (2–3 Weeks)
1. **Master size chart** — lock exact measurements for S/M/L/XL/XXL for shirts (core product first)
2. **Fit blocks** — physical reference garments per size, stored at Cotton factory
3. **Pre-drop QC** — every new drop measured against the block before any unit ships
4. **Tolerance bands** — written, numeric, enforced (e.g., ±0.5cm on chest, ±0.3cm on collar)
5. **Return analysis** — extract existing returns, cluster by size + product, identify worst drifts

**Owner**: Raghav + Naushi jointly. **Venue**: Cotton factory. **Timeline**: 2–3 weeks from decision.

### Escalation Triggers (Brain Tracking)
- Return rate crosses **15%** → escalate
- Fit complaints dominate review sentiment → escalate
- Repeat rate drops below **20%** → escalate

**Sprint 5 — The "Why This Over Zara" Story (Week 2)**
- Rewrite landing page, product pages, Instagram bio around vertical integration + fabric quality narrative

### Vhagar Menswear Typical Specs

| Product | Typical GSM | Typical Composition | Weave |
|---|---|---|---|
| **Shirts (core)** | 110–160 GSM | Cotton, poly-cotton, linen blends | Plain / twill |
| **T-shirts / jersey** | 160–220 GSM | Cotton jersey, poly-cotton | Knit |
| **Chinos / bottomwear** | 220–300 GSM | Cotton twill, poly-cotton | Twill |
| **Outerwear** | 300–500 GSM | Blends | Various |

### Fit-Spec Reference (to lock per garment type)

For shirts (core Vhagar product):
- Collar band (cm)
- Chest circumference (cm)
- Shoulder width (cm)
- Sleeve length (cm)
- Body length (cm)
- Sleeve opening circumference (cm)

**Tolerance bands to enforce** (example):
- Chest: ±0.5 cm
- Collar: ±0.3 cm
- Shoulder: ±0.5 cm

All tolerance bands stored at Cotton factory + Naushi's design files. Pre-drop QC checks every unit against the block.

### Shrinkage to Disclose
- Cotton shirts: 3–5% shrinkage expected. State pre-wash vs post-wash size on product pages.
- Poly-cotton blends: 1–3%
- Test-wash before every new fabric introduction

## SECTION 14 — TREND RADAR (VHAGAR APPLICATION)

Vhagar uses the group's 4-Signal Trend System for drop direction:

| Signal | What It Looks Like for Vhagar |
|---|---|
| **1. Customer Pull** | Reviews + DMs asking for specific styles, colors, fits |
| **2. Runway / Influence** | Instagram aesthetics, celebrity wardrobes, menswear reports |
| **3. Supply-Side Proof** | Linkd already printing that print style; Silk already stocking that base fabric |
| **4. Margin Test** | A small first drop of that style sold through at target margin |

**Decision rule**: 3 of 4 signals = pilot drop. 4 of 4 = full-confidence drop. Never commit a full drop on 1–2 signals.

**Vhagar-specific categories to watch**:
- Silhouette: oversized vs fitted (current Indian menswear cycle)
- Print: abstract / geometric / florals / solids with texture
- Fabric story: natural / sustainable angle (linen, organic cotton)
- Smart casual / elevated basics (sweet spot for 799–1799 aspiring premium)
