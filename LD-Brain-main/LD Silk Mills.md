### 3.8 High-Return Whale Phenomenon (New — Phase 1 ERP Finding)

**What it is**: A subset of broker-driven customers who use LD Silk as a de facto consignment warehouse. They place large orders, hold fabric for extended periods, then return at elevated rates. LD Silk absorbs all reverse logistics costs, and the gross margin on attempted revenue collapses to near-zero or negative on these accounts.

**Mechanism of margin destruction:**
- Fabric dispatched → partial/full return weeks later
- Return logistics cost (inbound freight + re-inspection + restocking) = 12–18% of attempted GMV
- Combined with commission paid to the sourcing broker on kept inventory, and mark-to-market loss on returned fabric that has aged, effective gross margin on high-return accounts can turn negative

| Weave | Description | Uses |
|---|---|---|

| **Twill weave** | Diagonal ribs | Denim, gabardine, chino |
| **Satin weave** | Long floats = luster | Eveningwear, linings |
| **Jacquard** | Complex patterns woven in | Brocade, damask, premium ethnic |
| **Dobby** | Small geometric patterns | Structured shirting |
| **Crepe** | Twisted yarns = pebbled texture | Dresses, blouses |

### GSM Reference

| GSM | Feel | Typical Use |
|---|---|---|
| <80 | Sheer | Voile, organza, linings |
| 80–120 | Light | Shirting, scarves |
| 120–180 | Medium-light | Shirts, tops |
| 180–240 | Medium | Suiting, dresses |
| 240–320 | Heavy | Jackets, trousers |
| >320 | Very heavy | Outerwear, denim, canvas |

### Hand-Feel Sales Vocabulary
- **Drape**: how fabric hangs (soft: crepe/satin; stiff: organza/taffeta)
- **Hand-feel**: smooth / rough / crisp / buttery / dry / slinky
- **Luster**: matte / soft luster / high luster
- **Body**: resistance to crumpling (low: chiffon; high: canvas)

**Rule**: Customers buy feel, not specs. Always translate specs → feel when selling.

### Fabric Defect Taxonomy (QC Reference)

**Yarn defects**: slubs, thin places, knots/joints, mixed count, contamination

**Weaving defects**: missing pick/end, float, broken pick, double pick, temple mark, reed mark, starting mark, selvage defects

**Finishing defects**: dye spots, color shading, crease marks, printing misalignment

**Physical defects**: holes, stains, abrasion, shrinkage exceeding tolerance
