## How Sublimation Printing Works

1. Design digitized in RGB/CMYK
2. Printed onto transfer paper using sublimation dye ink (this happens on the printing machines)
3. **Printed paper + plain grey fabric are fed together into the fusing machine** — this is the sublimation transfer step
4. Fusing machine applies heat (185–230°C) and pressure — dye turns solid → gas → embeds permanently into polyester fibers
5. Paper peels away; design is now physically inside the fabric (not on top)
6. Result: vibrant, washfast, feel-free print that is part of the fabric

> **Fusing is MANDATORY for every single job.** It is not a finishing option — it is the step that transfers the design from paper onto fabric. Without fusing, the design stays on the paper and the fabric remains plain. There is no sublimation printing without fusing.

## Critical Rule: Sublimation = Polyester ONLY

| Fabric Composition | Suitability |
|---|---|
| 100% polyester | Best results, brightest colors |
| Poly-rich blends (>65% poly) | Acceptable, slightly muted |
| Poly <50% | NOT suitable |
| Natural fibers (cotton, silk, linen) | NOT suitable — design washes off |

**Never promise sublimation on natural fibers. This is a non-negotiable quality rule.**

## Color Science

- **ICC profiles**: calibrate monitor → printer → fabric for consistent color. Must be maintained.
- **Delta E**: unit of color difference. <2 = imperceptible; 2–5 = noticeable; >5 = obvious mismatch.
- **Pantone matching**: achievable with calibration. Set expectations on day one — not all Pantone colors translate perfectly to poly.
- **Calibration cadence**: profile + ink batch checked weekly. Color drift kills repeat business silently.
- **D65 light box**: mandatory for color approval. No exceptions.

## Common Print Defects

| Defect | Cause |
|---|---|
| Banding | Visible horizontal stripes — printhead issues |
| Ghosting | Double image — fabric shift during press |
| Color drift | Hue changes across batch — ink/profile issues |
| Fading edges | Uneven heat press pressure |
| Spotting | Ink splatters or paper-defect transfers |
| Sharpness loss | Low DPI source files, paper quality, or temperature issues |

## Fabric Preparation for Printing

- Fabrics must be clean, dry, and flat
- Pre-press to remove moisture and wrinkles
- Consistent tension across the press bed
- Substrate type affects optimal temperature/time (heavier = higher temp, longer dwell)
