## Economics

- **Commission**: 1–2% on closed revenue (industry-standard)
- **Break-even**: Any agent sourcing >₹20L/year is worth keeping active
- **Return-rate caveat**: Commission economics assume standard return rates. Brokers >30% return rates have materially different P&L.
- **Net Broker Value formula**: Gross billed − Commission (2%) − Return cost

## MRT Protocol (>30% Return Rate Brokers)

Any broker with return rate above 30% triggers a mandatory structural conversation:

1. **Return cap agreement**: max X% return per quarter or forfeiture of commission on returned goods
2. **Pre-qualifying commitment**: broker takes responsibility for customer qualification before dispatch
3. **Restocking fee**: partial cost recovery on returns above the agreed threshold
4. **Order sizing discipline**: smaller pilot orders before large dispatches
