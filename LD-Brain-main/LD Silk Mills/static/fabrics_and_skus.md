> 1. **Who** buys this (named customer or segment)

- **Silk → Linkd**: Print-friendly SKUs (Tier 4) are Linkd's substrate library. Cross-sell the printing service.
- **Silk → Cotton**: Cotton's factory can cut/sew from Silk's inventory. Dead stock → captive garment input.
- **Silk → Vhagar**: "Made from our own fabric" — hero a handful of Silk's unique fabrics as Vhagar exclusives.

## Fabric Science Reference

### Fiber Properties

| Fiber | Key Properties | LD Silk Use |
|---|---|---|
| **Silk** | Luster, drape, strength | Core — Mulberry, tussar, eri, muga varieties |
| **Polyester (Poly)** | Durable, wrinkle-resistant, **sublimation-printable** | Largest print-substrate volume → Linkd |
| **Cotton** | Breathable, soft, absorbent | Shirting, commodity |
| **Viscose / Rayon** | Silk-like drape, lower cost | Blended apparel |
| **Blends** | Poly-viscose, poly-cotton, silk-cotton | Engineered for cost + performance |
| **Linen** | Cool, textured, slubs | Fashion / natural look |

### Weave Types

| Weave | Description | Uses |
|---|---|---|
| **Plain weave** | Over-under-over | Voile, poplin, taffeta, organza |
| **Twill weave** | Diagonal ribs | Denim, gabardine, chino |
| **Satin weave** | Long floats = luster | Eveningwear, linings |
| **Jacquard** | Complex patterns woven in | Brocade, damask, premium ethnic |
| **Dobby** | Small geometric patterns | Structured shirting |
| **Crepe** | Twisted yarns = pebbled texture | Dresses, blouses |

### GSM Reference

| GSM | Feel | Typical Use |
|---|---|---|
| <80 | Sheer | Voile, organza, linings |
| 80–120 | Light | Shirting, scarves |
| 120–180 | Medium-light | Shirts, tops |
| 180–240 | Medium | Suiting, dresses |
| 240–320 | Heavy | Jackets, trousers |
| >320 | Very heavy | Outerwear, denim, canvas |

### Hand-Feel Sales Vocabulary

- **Drape**: how fabric hangs (soft: crepe/satin; stiff: organza/taffeta)
- **Hand-feel**: smooth / rough / crisp / buttery / dry / slinky
- **Luster**: matte / soft luster / high luster
- **Body**: resistance to crumpling (low: chiffon; high: canvas)

**Rule**: Customers buy feel, not specs. Always translate specs → feel when selling.
