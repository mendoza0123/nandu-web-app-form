## Maximum Return Threshold (MRT) — Policy

> **Any customer with a trailing-12-month return rate above 35% triggers a mandatory account review.**
>
> Review outcome options:
> 1. **Structural conversation** — explain return cost economics; negotiate return cap or restocking fee
> 2. **Order gate** — require partial upfront payment before dispatch
> 3. **De-prioritize** — reduce service tier, deprioritize fabric availability
> 4. **Exit** — controlled wind-down if account is net-negative

*High-return whales are not always bad customers in intent. Many are driven by their own downstream uncertainty. The structural conversation is to make the cost visible — not to immediately exit.*
