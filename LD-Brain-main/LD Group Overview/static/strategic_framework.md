## Operating Principles (How the Brain Thinks)

1. **First principles > best practices.** LD is a 35-year Indian textile house, not a SaaS startup.
2. **North Star filter**: Does this fill idle capacity at margins above floor? Does it multiply principal leverage?
3. **Show the math.** Every recommendation names numbers. "It depends" is banned.
4. **80/20 ruthlessly.** Silk concentration, Cotton fill, Linkd sales motor, Vhagar fit — these are the levers. Everything else is noise.
5. **Every answer ends in an action step**: who, by when, success metric.
6. **Data gaps are first-class citizens.** Name the gap; name how to close it.
7. **Protect principal time.** Any recommendation that adds calendar without subtracting something else is rejected.
8. **Gross revenue is a vanity metric for any channel with variable returns.** Net Broker Value = (gross billed × net retention rate) − reverse logistics cost − commission. Rank all agents/channels by net contribution, never gross.
9. **Return rate is a margin metric, not a service metric.** Any broker, SP, or channel partner with a trailing-12-month return rate >30% is a structural conversation candidate.

## Resource Allocation Scoring

Use this framework for any initiative:

| Dimension | Question | Weight |
|---|---|---|
| Revenue potential | Revenue unlock in 12 months? | ×3 |
| Speed to revenue | How fast does first rupee arrive? | ×2 |
| Principal-time cost | Hours/week from which principal? Maxed? | ×2 |
| Capacity fill | Fills Linkd meters or Cotton garments at margin? | ×2 |
| Self-funding speed | Generates cashflow to fund next step? | ×2 |
| Strategic multiplier | Compounds over multiple quarters? | ×1 |

**Hard vetoes**:
1. Capacity fill = 0 → deprioritize
2. Requires maxed principal with no hire plan → blocked
3. Requires external capital → blocked absolutely

## Growth Scenarios

**Current state**: ~90–100 Cr | **Target**: 1,000 Cr in 3–5 years | **North star**: 5,000 Cr in 10–15 years

### Scenario A — Organic (insufficient)
- Silk ~15%/yr | Linkd ~40%/yr | Cotton slow ramp | Vhagar small
- **Outcome**: ~250–350 Cr in 5 years. Not enough.

### Scenario B — ACCELERATED (RECOMMENDED)
- **Silk**: Agent activation + wallet share + concentration defense → 20–25%/yr → 150–200 Cr by Y5
- **Linkd**: NBD hire + price floor + Silk cross-sell → 60%/yr → 80–100 Cr by Y5
- **Cotton**: Cert sprint + external sales → steady scale → 400–500 Cr by Y5
- **Vhagar**: Fit lock + brand story → 50–100 Cr by Y5 if PMF real
- **Outcome**: 700–900 Cr. Close. Extra push hits 1,000 Cr.
- **Requires**: Execute playbooks on calendar; hire 3–4 roles this year; fix founder time via brain.

### Scenario C — Aggressive (post-Y2 add-on)
- Cotton capacity expansion, export push, Vhagar multi-category, Group COO hire
- **Outcome**: 1,200–1,500 Cr. Only pursue after Scenario B is on track.
