## Inter-Company Flow Rules

- **Silk → Linkd**: ~126,865 mtrs/month captive jobwork *(Linkd ERP verified: 15,22,383 mtrs T12 = ₹5.60 Cr)* at ₹36.75/mtr implied avg. Break-even for Linkd.
- **Cotton → Linkd**: ~1,087 mtrs/month captive printing *(13,041 mtrs T12 = ₹4.93L)*. NOTE: SAB CUST2517 = 130,981 mtrs = Cotton BUYING fabric FROM Silk — different flow entirely.
- **Silk → Linkd (cross-sell)**: 4 external customers verified buying both. 728 Silk customers never used Linkd = zero-CAC pipeline.
- **Cotton → Vhagar**: Captive garmenting. Vhagar is Cotton's anchor customer.
- **Linkd → Vhagar**: All Vhagar prints from Linkd's own machines.
- **Silk → Cotton**: Dead stock fabric → Cotton raw material → finished garments (vertical flywheel).
